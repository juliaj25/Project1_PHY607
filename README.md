# Damped Oscillator

ODE and integral solver for a damped oscillator 
## Installation

1. Clone the repository:

```bash
git clone https://github.com/juliaj25/Project1_PHY607.git
cd Project1_PHY607
```

## Running the Code

You can run the code from the command line using:
```bash
python project1code.py --mass 1.0 --damping 0.1 --spring 1.0

```

### Arguments
`--mass`: Mass of oscillator

`--damping`: Damping coefficient 

`--spring`: Spring constant

## Output:

Outputs a graph of the solutions from each ODE solver. Additionally, it ouputs the values from calculating work for each integral solving method. Finally, it outputs the change in energy of the system.
